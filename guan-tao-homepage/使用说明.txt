关涛的中英双语个人学术主页
============================

一、先看网站
解压后，用浏览器打开 index.html 即可查看中文首页，点击右上角 English 可切换到英文。
首页、论文发表、教育与荣誉三个栏目均有中英文页面。
页面不依赖在线字体或外部脚本，离线也能浏览；论文外链需联网。

二、发布到 GitHub Pages
1. 登录你的 GitHub 账号 TaoGuan1998。
2. 打开你已创建的公开仓库：https://github.com/TaoGuan1998/github.io
   进入 Settings → General，在 Repository name 中把 github.io 改为 taoguan1998.github.io，然后点击 Rename。
   改名后的仓库地址为 https://github.com/TaoGuan1998/taoguan1998.github.io 。
   2026-10-22 检查时原仓库为空。如已有新内容，请先查看，避免覆盖。
3. 在当前空仓库页面的 Quick setup 区域点击 uploading an existing file，上传本文件夹内的全部文件和子文件夹。
   仓库有文件后，对应入口为 Add file → Upload files。
   应让 index.html 直接位于仓库最外层，不要再套一层 guan-tao-homepage 文件夹。
   上传解压后的文件，不是 ZIP 文件本身。保留 assets 和 en 子文件夹。
   .nojekyll 是一个空文件；浏览器上传遗漏它时，可在仓库中补建同名空文件。
4. 点击 Commit changes 保存。
5. 打开 Settings → Pages。
   Source 选择 Deploy from a branch，Branch 选择 main，文件夹选择 / (root)，保存。
6. 等待 GitHub 完成发布，然后使用 Pages 页面里的 Visit site 打开网站。
   按上述仓库名发布后，网站地址为 https://taoguan1998.github.io/ 。
   这个地址需要完成上传并开启 Pages 后才能访问。

GitHub 官方说明：
https://docs.github.com/en/pages/quickstart
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

三、内容与维护
本版本依据你提供的简历整理，已去掉专利和项目，没有附上包含这些内容的原始简历。
保留姓名、照片、邮箱、研究方向、教育经历、11 篇期刊论文及荣誉。
手机号、微信、籍贯、出生年月不作为独立信息展示。
博士毕业时间使用“预计 2027 年 6 月”。
中文论文在英文页面保留原题，另附明确标注的英文译名。
没有确认论文地址的条目使用明确标注的“学术检索”，没有编造论文 PDF 或代码链接。
院校、学位、荣誉、论文年份按所提供简历整理；英文荣誉名称为说明性翻译。

日常更新可以继续把新内容发给我处理。
如自行修改：文字与页面结构在 build.mjs 中，论文数据与邮箱在 content.json 中，样式在 assets/style.css 中。
修改内容后，安装了 Node.js 的电脑可在此文件夹运行 node build.mjs 重新生成全部六个页面，再上传更新后的文件。
网站部署本身不需要 Node.js 或其他构建工具，生成的 HTML 可以直接托管。
在 content.json 的 github 字段填写真实用户名并重新生成，可显示 GitHub 主页链接。
